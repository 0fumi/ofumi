# 📬 御文（Ofumi）

毎朝30分で読める、QAエンジニア向けの技術雑誌。

御文は「情報を集める場所」ではなく、

> **今日読むべき一冊を、迷わず開けること**

を目的としたAndroidアプリです。

---

# コンセプト

* 📖 毎朝30分で読み切れる
* 🎯 編集部が価値を編集する
* 💡 読むだけで終わらず、仕事へ持ち帰る
* 📱 雑誌のような読書体験を提供する

---
